# + rolê

Site do + rolê (eventos e criação de conteúdo). HTML estático, sem build.

- `index.html` — Home
- `arte.html`, `esportes.html`, `politica.html`, `educacao.html` — categorias
- `*-evento1/2/3.html` — páginas de evento de cada categoria
- `assets/` — imagens e fontes

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `mais-role`).
2. Envie todo o conteúdo desta pasta para a raiz do repositório (`index.html` precisa ficar na raiz).
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Em ~1 minuto o site fica em `https://SEU-USUARIO.github.io/mais-role/`.
